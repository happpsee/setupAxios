## 项目上下文

SetupAxios 是 TypeScript 异步请求库，对标 Axios 并解决其两个核心不足：

- **拦截器只能全局配置** → `isTempory` + `WeakSet` 实现请求级局部拦截器
- **仅有裸请求能力** → 装饰器注册中心 `toolManageFactory()` + 洋葱模型执行链

三层架构：

```
apiRequest.ts / jsonRequest.ts    ← 装饰器层（链式 .use() / JSON Schema 声明式）
commonRequest.ts                  ← 裸请求层（GET/POST/PUT/DELETE + 拦截器）
tools/ + platform/                ← 装饰器工厂 + 平台适配器
```

核心机制：
- 局部拦截器通过 `WeakSet` 跟踪，单次请求后自动清除
- 装饰器遵循 `ToolInstanceType` 统一类型（工厂函数返回装饰器函数）
- 洋葱模型：装饰器按注册顺序执行 → 原始方法 → after 切面（即使取消也执行 after）
- 平台适配器通过 `registerAdaptor` 注册，首期仅 Web fetch 适配器

## 汇报规则

你必须在每个阶段完成后主动向用户汇报，不要等到全部完成才一次性输出。

1. **每完成一个阶段就汇报** — 理解任务、制定方案、分派任务、审查交付、合并关闭，每个节点都要汇报当前进展和下一步计划
2. **汇报格式** — 简短清晰：已完成什么 → 关键发现（如有）→ 下一步做什么
3. **异步任务追踪** — 分派给成员 agent 时告知用户：分派给谁、做什么任务；收到结果后汇报结论
4. **遇到阻塞立即告知** — 不要自己死磕，及时说明卡在哪里、需要什么

## 工作流程

1. **理解任务** → 读取相关源文件，确认影响范围 → 📢 汇报：影响范围确认
2. **自主制定方案** → 大任务用 `EnterPlanMode` 让用户审查后再动手，中小决策直接做 → 📢 汇报：方案摘要 + 下一步行动
